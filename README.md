# Behaviors e comandos em Xamarin.Forms

> Exemplo de Behavior para conectar eventos da interface a comandos em uma aplicação Xamarin.Forms.

## Organização

- `Droid/` — projeto da plataforma Android.
- `EventCommandExample.Tests/` — projeto de testes.
- `EventCommandExample/` — projeto ou módulo `EventCommandExample`.
- `iOS/` — projeto da plataforma iOS.

Solução: [`EventCommandExample.sln`](EventCommandExample.sln).

## Tecnologias

C#, Xamarin.Forms e projetos para Android e iOS.

## Como abrir

Abra [`EventCommandExample.sln`](EventCommandExample.sln) no ambiente de desenvolvimento compatível com a stack do projeto.
